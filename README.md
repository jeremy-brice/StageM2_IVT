# M2 Internship

## Vertically integrated moisture transport : trends over Nepal and the Pamir

This directory contains all the codes and figures produced during the Master 2 internship carried out with María Santolaria-Otín and Martin Ménégoz.

The aim of this work was to better understand atmospheric circulation evolution in High Mountain Asia, its local reponse in precipitation and temperature and the impact it had on glacier evolution. The main goal was to better understand the spatial contrast in glacier evolution in the region between the western part (limited glacier mass loss) and the south / southeastern part (pronounced glacier mass loss).

The GitHub file is organized as follow : 

- **stageM2_micro.yml** : micromamba environment used in this study
-  **internship_repport_jeremy_brice.pdf** : report of the intership for the Master's Degree
-  **oral_presentation_jeremy_brice.pdf** : oral presentation of the internship for the Master's Degree.

- **report_figures** : notebooks to make exactly the final figures of the report as well as the appendix.
- **library** : function definitions used across the study. In domain.py, the function used to define the domains used in the study. In climbas.py the function used to make the climatology and seasonal trends.
- **script** : python files to compute data, that were then used in the study.

The other files are all the notebooks or python files that were coded during the internship, it is a little bit more messy :

- **climbas** : climatology and seasonal trends for the variables used in the study.
- **annual_cycle** : annual cycle of different variables.
- **dom_def** : definition of the 5 regions used to better understand the atmospheric circulation and its precipitation response.
- **extrem_events** : daily description of atmospheric circulation and precipitation response for the 2013, 2014, 2021 and 2025 extrem precipitation events.
- **papier** : everything related to glacier evolution. Regional definition, glacier evolution, atmospheric drivers.
- **spatial_temporal_coverage_observations_datasets** : data directly available in the observational precipitation datasets (APHRO, CRU, GPCP) for spatial and temporal station coverage.
- **time_series** : time series for the different variables used in the study.
- **MAR** : little study about MAR in the region. Climatology and trends of precipitation temperature, and surface mass balance in Nepal and the Pamir.
